# Мой Магазин V25.1 — Test Build

Текущая тестовая версия экономического симулятора.

## Что можно протестировать

- движение покупателей;
- выбор товаров и корзина до 3 товаров;
- списание товара с полки;
- очередь и работа кассира;
- продажа и выручка;
- склад и автоматическая выкладка продавцом;
- поставщики и доставка;
- закупочная стоимость;
- спрос и рекомендованные цены;
- скидки;
- персонал и улучшения;
- расширение магазина;
- реклама;
- аналитика;
- сохранение прогресса в localStorage;
- ручное сохранение;
- завершение игрового дня;
- полный сброс прогресса для нового теста.

## GitHub Pages

Файл `index.html` находится в корне репозитория и готов для публикации через GitHub Pages.

После включения Pages адрес будет:
https://mahti01.github.io/My-shop/

GitHub Pages публикует статические файлы из выбранной ветки/папки; для этого проекта рекомендуется `main / (root)`.
