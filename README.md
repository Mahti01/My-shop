# Мой Магазин V25 — Visual Gameplay

V25 развивает визуальный стиль магазина в технической части: полноценный цикл покупателей, выбор товара, корзина, очередь, касса, оплата, склад, автоматическая выкладка продавцом, поставщики, доставка, цены, спрос, акции, персонал, развитие и аналитика.

Сохранение: localStorage `myshop_v25`. При первом запуске V25 пытается перенести прогресс V23.

Для Netlify: `index.html` должен находиться в корне архива.
